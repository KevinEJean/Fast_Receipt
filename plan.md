## Fonctionnalité primaire

- Scraping des données d'une facture physique
- Structurer les données
- Afficher les données structurées
- Automatisation du pipeline de données
- Sécuriser le service
- Déployer l'application sur un serveur en continu

## Fonctionnalité optionnelle

- Fonctionnalité de l'application sur ordinateur
- Conversion de données semi-structurées (`JSON`, `CSV`) en données structurées (Dashboard, Tableau)
- Génération de fichier (`Excel`, `JSON`, `CSV`) avec les données structurées
