## Fonctionnalité primaire

- Scraping des données d'une facture physique (`PyTorch, OCR, ML`)
- Structurer les données (`Data lake`)
- Afficher les données structurées (`Data warehouse`)
- Automatisation du pipeline de données (`Jenkins, Git`)
- Sécuriser le service (`JWT, RBAC, CORS, basic security, dotenv`)
- Déployer l'application sur un serveur en continu (`Render, HTTP -> HTTPS, certs`)

## Fonctionnalité optionnelle

- Fonctionnalité de l'application sur ordinateur (additional web security)
- Conversion de données semi-structurées (`JSON, CSV`) en données structurées (Dashboard, Tableau)
- Génération de fichier (`Excel, JSON, CSV`) avec les données structurées
