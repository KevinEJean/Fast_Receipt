## 🔍 Description

<p align="justify">Une application mobile intelligente qui simplifie la gestion et la visualisation des dépenses. L'utilisateur prend simplement une photo de son reçu papier, et un modèle d'apprentissage automatique (ML) analyse et extrait instantanément les données clés (marchand, date, articles, taxes, total), accompagné d'un tableau de bord frontend qui génère en temps réel des graphiques interactifs, des suivis de budget et des rapports financiers détaillés.</p>

> Vidéo démo

## 🎯 Objectif

<p align="justify">Plusieurs contracteurs et travailleurs indépendants accumulent des factures et calculent manuellement leurs rapports financiers. FastReceipt remplace tout ce processus, mais il ne s'arrête pas seulement là. Les bases de données sont persistantes, et un tableau de bord affiche des graphiques importants pour la gestion financière.</p>

## ✔️ Instalation

0. Prérequis

- Git
- Node.js
- [Expo Go](https://expo.dev/go)

2. Lancer l'application

- Dans un terminal :

```bash
git clone <GitHub_Repository_URL>
cd Fast_Receipt
npm i
npx expo start
```

2. Scanner le code QR puis suivre les instructions qui apparaissent à l'écran.
